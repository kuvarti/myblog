## Rule
Write everything committed to the repository in English: documents, and code comments. The only exception is proper nouns (names of people, products, places), which may keep their original form.

Existing Turkish comments already in the codebase are grandfathered — leave them as they are, do not do a sweep to translate them. The English rule applies to comments you write or edit from now on.

## Rationale
The owner requires English-only artifacts in the repository, even though conversation with the owner happens in Turkish.

## Applies to
CLAUDE.md, READMEs, any other document, and code comments — anything written into the repo. Chat conversation is not affected (that is covered by [[communication-chat-language]]); only the committed artifacts must be English.
